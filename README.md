# Ephemeris

## Stack

- **Backend:** Spring Boot, JDBC, Postgres
- **Frontend:** Vite + React
- **Ops:** Docker Compose, nginx, `opstools/`

## Local

# backend
```bash
cd backend && ./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
```

# frontend
```bash
cd frontend && npm install && npm run dev
```
